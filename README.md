# Precios Minoristas en Supermercados de Argentina

Análisis de precios minoristas reportados diariamente por supermercados de Argentina, basado en datos públicos del sistema de transparencia de precios.

## Fuentes de datos

- **Datos abiertos del gobierno argentino**: Precios reportados por supermercados bajo el programa de transparencia de precios ([datos.gob.ar](https://datos.gob.ar/dataset/sspe-precios-claros))
